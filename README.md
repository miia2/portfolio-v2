Navegue até a pasta do frontend e instale os pacotes de dependências.

cd ../frontend
npm install

Configuração de Conexão: Abra o arquivo src/services/api.ts e certifique-se de que a propriedade baseURL aponta para o endereço correto da sua API (seja http://127.0.0.1:8000 executando localmente, ou o link do seu deploy na Render).

Para iniciar o painel em modo de desenvolvimento:

npm run dev
